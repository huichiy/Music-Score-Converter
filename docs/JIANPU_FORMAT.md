# 简谱文本格式 · Jianpu Text Format

文本编辑器（Route B）用的格式说明，方便手动编辑/复制粘贴。

---

## 描述头

```
Title: Ivory Voyage
Key: C   Time: 4/4   Tempo: 120
```

- `Title:` 曲名（可省）— 整行剩余内容都是标题
- `Key:` 调号 — `C` `G` `D` `A` `E` `B` `F#` `C#` `F` `Bb` `Eb` `Ab` `Db` `Gb` `Cb`
- `Time:` 拍号 — `4/4` `3/4` `6/8` 等
- `Tempo:` 速度（可省）— BPM 整数

> 注意：描述头必须在文本的**前 4 行**内，字段名**大小写敏感**（`key:` 小写不识别）。

---

## 音符

| 写法 | 含义 |
|------|------|
| `1` `2` `3` `4` `5` `6` `7` | 度数 |
| `0` | 休止符 |

### 八度

| 写法 | 含义 |
|------|------|
| `1'` | 高八度（+1） |
| `1''` | 高八度×2（+2） |
| `1,` | 低八度（-1） |
| `1,,` | 低八度×2（-2） |

### 升降号（写在音符前）

| 写法 | 含义 |
|------|------|
| `#1` | 升号 |
| `b1` | 降号 |

---

## 时值

简谱视觉上，时值由「减时线」（数字下面的横线）和「增时线」（数字后的横线）表示。文本格式直接映射这套视觉：

| 写法 | 拍数 | 含义 |
|------|------|------|
| `1` | 1 | 四分音符（默认） |
| `1-` | 2 | 二分音符 |
| `1--` | 3 | 附点二分音符 |
| `1---` | 4 | 全音符 |
| `1/` | 0.5 | 八分音符（一条减时线） |
| `1//` | 0.25 | 十六分音符（两条减时线） |
| `1///` | 0.125 | 三十二分音符（三条减时线） |
| `1.` | 1.5 | 附点四分音符 |
| `1./` | 0.75 | 附点八分音符 |
| `1.//` | 0.375 | 附点十六分音符 |
| `1.///` | 0.1875 | 附点三十二分音符 |

### 独立延音 token

`-` 单独成 token 时表示「延长前一个音一拍」，结果跟紧贴写法等价（休止符同样适用）：

```
1 - - -   等价于   1---   （全音符）
0 - - -   等价于   0---   （整小节休止）
```

### 跨小节延音（tie）

小节**开头**的 `-` 表示延续上一小节最后一个音（连结线），一个 `-` 一拍：

```
| 1--- | ---- | 2 3 4 5 |    ← 第二小节整小节延续 1
```

## 力度

写在小节开头（`|` 之后第一个 token），作用整个小节：

| 写法 | 缩写 | 含义 |
|------|------|------|
| `&pp` | pianissimo | 很弱 |
| `&p` | piano | 弱 |
| `&mp` | mezzo piano | 中弱 |
| `&mf` | mezzo forte | 中强 |
| `&f` | forte | 强 |
| `&ff` | fortissimo | 很强 |
| `&fff` | fortississimo | 极强 |
| `&fp` | fortepiano | 强后立即弱 |
| `&sfp` | sforzando-piano | 突强后立即弱 |
| `&sfz` | sforzando | 突强重音 |

例：
```
| &mf 1 2 3 4 | 5 6 7 1' |
```

> `&` 后面的字母不做校验——拼错（如 `&hello`）也会原样画到谱上。

---

## 渐强渐弱（hairpins）

独立 token，跨多个音/小节：

| 写法 | 含义 |
|------|------|
| `<` | 渐强开始 |
| `>` | 渐弱开始 |
| `!` | 结束（cresc / dim 终点） |

例：
```
| 1 2 3 4 | < 5 6 7 1' | 1 2 3 4 ! | 5- |
```

---

## 单音表情（articulations）

写在音符**后面**，用方括号包起来。

| 写法 | 名字 | 含义 |
|------|------|------|
| `1[>]` | accent | 重音 |
| `1[.]` | staccato | 短促、断开 |
| `1[-]` | tenuto | 完整保持时值 |
| `1[^]` | marcato | 强重音 |
| `1[$]` | fermata | 自由延长 |

---

## 倚音

也用方括号，但**里面是音符**（数字），系统自动识别：

| 写法 | 含义 |
|------|------|
| `1[2]` | 2 装饰 1（先快速吹 2，再吹 1） |
| `1[#2]` | 倚音可带升降号 |
| `1[2']` | 倚音可带八度 |

**规则**：方括号里是符号 → 表情记号；是数字 → 倚音。

---

## 和弦 / 双音

主音后用 `:` 接和弦音（可叠多个），时值写在整个 token 末尾，作用于整个和弦：

| 写法 | 含义 |
|------|------|
| `5:3` | 5 和 3 同时奏（3 显示在 5 下方） |
| `5:#3,` | 和弦音可带升降号和八度 |
| `6:4:1-` | 三个音的和弦，整体二分音符 |

---

## 连线（slur）

用圆括号包起来：

```
( 1 2 3 )
```

括号内所有音连奏（吹奏时不断气）。

---

## 小节线

| 写法 | 含义 |
|------|------|
| `\|` | 普通小节线 |
| `\|\|` | 双竖线（段落分隔） |
| `\|:` | 反复开始 |
| `:\|` | 反复结束 |
| `\|\|&fine` | Fine 终止 |
| `\|\|&dc` | D.C.（从头反复） |
| `\|\|&ds` | D.S.（从记号反复） |

---

## 多小节休止压缩

```
[N]
```

例：`[8]` 表示 8 小节休止（用方块括起来的数字）。

---

## 完整示例

```
Key: G   Time: 4/4   Tempo: 100

| &mf 1 2 3 4 | < 5/ 6/ 5/ 4/ 3- ! | #4[>] 5. 3.// 2// 1[$] :|
```

解读：
- `Key: G   Time: 4/4   Tempo: 100` — G 调，4/4 拍，100 BPM
- 第 1 小节：mf 力度，四个四分音符 1 2 3 4
- 第 2 小节：渐强开始，四个八分音符 5 6 5 4，然后 3 拍二分音符，渐强结束
- 第 3 小节：升 4 带重音，附点四分 5，附点十六分 3，十六分 2，1 加 fermata，反复结束

---

## 跟番茄简谱的区别

我们的格式参考了 [番茄简谱脚本](http://doc.lezhi99.com/zhipu)，但有几处不同：

| 概念 | 我们 | 番茄 |
|------|------|------|
| 升降号位置 | 音符前：`#1` | 音符后：`1#` |
| 二度八度 | 支持：`1''` `1,,` | 不支持 |
| 多小节休止 | `[N]` 压缩 | 写 N 个 `0` |
| 歌词 / 多声部 | 不支持 | 支持 |
| 装饰音 | `1[2]` | `1[2]` |

---

## 已知限制

- **MusicXML 导入后**：力度、反复、渐强、连线、Fine/D.C./D.S. 会保留并可在文本编辑器里看到/修改。
- **倚音、表情记号**：渲染支持；但 MusicXML 导入暂不解析这些，需要手动在文本里加。
- **跳房子（volta）、三连音、笛子专属技巧**（颤音/波音/叠音/打音/花舌等）：暂不支持，等用户反馈再加。
